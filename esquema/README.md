# esquema/

Projeto EasyEDA editável e a exportação em PDF.

O esquema deve conter os dois potenciômetros, o Arduino, os barramentos, os
botões, o comparador, a habilitação, o somador e a lógica dos LEDs, além da
alimentação, dos componentes, da identificação do grupo e das notas de
modelagem e de testes. Deve representar o protótipo efetivamente montado.
